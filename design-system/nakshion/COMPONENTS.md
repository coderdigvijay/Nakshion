# Nakshion Components

> Companion to `MASTER.md`. Every value below is a token from `tokens.css`; class strings are Tailwind v4 utilities generated by those tokens.
> Build with `class-variance-authority` + `cn()` (`frontend/src/lib/utils.ts`). Hand-built, no Radix/shadcn.
> **Global state grammar** (applies to every interactive component unless overridden):
>
> | State | Treatment |
> |---|---|
> | hover (pointer only — `@media (hover:hover)`) | one step up the tone ladder or the `-hover` token; 150 ms `ease-standard` |
> | focus-visible | `focus-ring` utility: 2px `focus` outline, 2px offset. Never removed. |
> | active / pressed | `-pressed` token + `scale-[0.98]`, 100 ms |
> | disabled | `fg-disabled` text, `elevated` bg, no shadow, `cursor-not-allowed`; use `aria-disabled="true"` (keeps it focusable for an explanatory tooltip) when the reason isn't obvious |
> | loading | `aria-busy="true"`, width locked, interaction blocked, spinner or skeleton; label announces via sr-only text |
> | error | `danger` border/text + `AlertCircle` + message; `aria-invalid` + `aria-describedby` |

## Button

**Anatomy:** `[leading icon?] label [trailing icon?]` · gap 8px · `rounded-control` · Inter 600 · sentence case.

```ts
type ButtonProps = {
  variant?: "primary" | "secondary" | "ghost" | "ai" | "danger" | "link";
  size?: "sm" | "md" | "lg";
  loading?: boolean;
  as?: "button" | typeof Link | "a";   // never wrap <Link> around <Button>
  fullWidth?: boolean;
} & React.ComponentPropsWithoutRef<"button">;
```

| Size | min-height | padding-x | text | icon |
|---|---|---|---|---|
| sm | 36px (+4px invisible hit-slop each side → 44) | 12px | 14px | 16 |
| md (default) | 44px | 20px | 15px | 18 |
| lg | 52px | 28px | 16px | 20 |

| Variant | Rest | Hover | Pressed | Notes |
|---|---|---|---|---|
| **primary** | `bg-accent text-on-accent` | `bg-accent-hover shadow-glow-accent` | `bg-accent-pressed` | **One per view** (P3). Light theme adds `shadow-e1`. |
| **secondary** | `bg-surface text-fg border border-border-strong` | `bg-elevated` | `bg-elevated` + scale | Default for everything that isn't the one primary. |
| **ghost** | `text-fg-secondary` transparent | `bg-elevated text-fg` | — | Toolbars, tertiary actions. |
| **ai** | `bg-ai-fill text-on-ai` | `brightness-110 shadow-glow-ai` | `brightness-95` | Only for "Ask Nakshion" / Send. Prefixed by `Sparkles`. |
| **danger** | `bg-danger-fill text-on-danger` | `brightness-110` | `brightness-95` | Only inside confirm dialogs. Elsewhere use a `secondary` button with `text-danger`. |
| **link** | `text-ai underline-offset-4` | `underline` | — | Inline in prose; min 44px height when standalone. |

**Loading:** keep measured width (`min-w` set from first render), replace leading icon with `Loader2` 16px `animate-spin`, keep the label (or swap to progressive verb: "Generating…"). `aria-busy="true"`, `disabled`. Reduced motion: spinner static, label carries meaning.
**Full-width** on mobile for the primary action of a form or sheet; inline on ≥640.
**Content:** verb-first, ≤ 3 words where possible ("Generate chart", "Ask about today"). Hindi labels may wrap to 2 lines — never truncate.
**Don'ts:** no gradients, no uppercase, no `hover:scale-105` (layout jitter), no `rounded-full` (that's IconButton/Chip).

## IconButton

Square or round button containing only an icon. `aria-label` is a **required** prop in the TS type.

| Size | box | icon |
|---|---|---|
| sm | 36 (hit-slop to 44) | 16 |
| md | 44 | 20 |
| lg | 52 | 24 |

Variants: `ghost` (default — `text-fg-secondary`, hover `bg-elevated text-fg`), `secondary` (bordered), `primary` (gold, round — FAB only), `ai` (round — chat Send).
Shape: `rounded-control` default; `round` prop → `rounded-chip`.
Tooltip: shows `aria-label` text on hover/focus after 500 ms, `overlay` bg, `text-caption`, `rounded-control`, offset 8px. Toggle buttons use `aria-pressed`.

## Input / Field

`Field` wraps any control with label, hint, error and wiring; `Input` is the bare control. Works with React Hook Form `register` (forwardRef).

**Anatomy (top→bottom):** Label (14px Inter 500 `fg-secondary`, optional "Optional" suffix in `fg-muted`) · 8px · Control · 6px · Hint (13px `fg-muted`) **or** Error (13px `danger` + `AlertCircle` 16).

| Property | Value |
|---|---|
| Height | md 48px, sm 40px (textarea: min 96px, auto-grow) |
| Padding | 16px x; 44px right when a suffix icon exists |
| Text | **16px** `fg` (prevents iOS zoom); placeholder `fg-muted` |
| Background | `bg-field` |
| Border | 1px `border-strong` (3.17:1+, meets 1.4.11) |
| Radius | `rounded-control` |
| Focus | border `ai` + `ring-4 ring-ai/25` (inputs show focus on `:focus`, not only `:focus-visible`) |
| Error | border `danger`, ring `danger/25` on focus; message replaces hint |
| Disabled | `bg-elevated text-fg-disabled border-border` |
| Read-only | `bg-transparent border-dashed` |
| Prefix/suffix | 20px icon `fg-muted`, 14px from edge |

**Password:** suffix IconButton `Eye`/`EyeOff`, *reachable by keyboard* (no `tabIndex={-1}`), `aria-pressed`, `aria-controls`.
**Validation:** on blur, then live once a field has errored. On submit focus the first invalid field. Error copy: what + how ("Enter a date between 1900 and today").
**a11y:** `<label htmlFor>`; `aria-describedby` → hint/error ids; `aria-invalid`; `aria-required` (and visual "Optional" marking on the minority, not asterisks on the majority).
**Don't:** uppercase + `tracking-widest` labels (current `Input.tsx`) — illegible in Devanagari and shouts.

## Select

**Default: native `<select>`** styled to match Input (appearance-none, `ChevronDown` 20 suffix, same metrics). Native gives the best mobile pickers and free a11y. Use for ≤ 20 static options (month, relationship type, language, chart style).
**Custom Listbox** only when options need rich content (avatars, glyphs): button `aria-haspopup="listbox"`, listbox `rounded-card bg-overlay shadow-e2 border border-border`, options 44px, selected `ai-subtle` + `Check`, ↑/↓/Home/End/type-ahead, Esc closes, focus returns.

## BirthDate / BirthTime pattern

Birth data is the single most important input in the product — it determines every reading. Native `<input type="date">` forces a decades-long scroll on mobile and has inconsistent locale order; replace it.

### BirthDateField
`<fieldset>` with `<legend>Date of birth</legend>` containing three controls on one row:

| Segment | Control | Width | Notes |
|---|---|---|---|
| Day | `<input inputmode="numeric" maxlength=2 autocomplete="bday-day">` | 72px | placeholder "DD" |
| Month | native `<select autocomplete="bday-month">` with localised month names | flex-1 | "March" / "मार्च" |
| Year | `<input inputmode="numeric" maxlength=4 autocomplete="bday-year">` | 96px | placeholder "YYYY" |

- Order follows locale: `en-IN`/`hi` → D M Y; `en-US` → M D Y.
- Auto-advance focus after a complete Day/Year entry; Backspace on empty segment goes back.
- Validation (on fieldset blur): real calendar date, not in the future, year ≥ 1900. One error message for the group, under the row.
- **Live confirmation line** under the field (`text-body-sm fg-secondary`, `aria-live="polite"`): "Tuesday, 14 March 1995". Users catch D/M swaps here.

### BirthTimeField
- Row: Hour (`inputmode=numeric`, 1–12) · ":" · Minute (00–59) · AM/PM segmented control (44px). 24-hour mode if locale prefers.
- **Checkbox "I don't know my exact birth time"** (custom 20px box, 44px row hit area). When checked:
  - time row collapses (grid-rows `1fr→0fr`, 250 ms — not `height`).
  - shows **"Roughly when?"** Chips (single-select): Morning (6–12) · Afternoon (12–17) · Evening (17–21) · Night (21–6) · No idea.
  - Info note (`info-subtle` bg, `Info` icon, `rounded-control`, 13px): "Without an exact time, your Lagna (Ascendant) and houses may be off. Planet signs and your Moon nakshatra stay accurate." (P2: honest about precision.)
- Precision badge on the saved profile: `Exact time` (success) / `Approximate` (warning) / `Time unknown` (neutral).

## LocationAutocomplete

ARIA 1.2 combobox, backed by `useLocationSearch` (LocationIQ).

**Anatomy:** Field label "Place of birth" · input (Search icon prefix, status suffix) · listbox popover · resolved-place summary.

| Behaviour | Spec |
|---|---|
| Trigger | ≥ 2 chars, 300 ms debounce, cancel stale requests |
| Suffix | idle `Search` · searching `Loader2` spin · resolved `CheckCircle2` in `success` · error `AlertCircle` `danger` |
| Listbox | `bg-overlay rounded-card shadow-e2 border border-border`, max 6 options, max-h 320, 8px gap below input; on mobile <640 opens as a full-height Sheet with the input pinned at top (keyboard-safe) |
| Option | 56px: `MapPin` 16 `fg-muted` · **City** 15px `fg` (matched substring in 600) / region, country 13px `fg-muted` |
| Keyboard | ↓/↑ moves `aria-activedescendant`, Enter selects, Esc closes and keeps typed text, Tab selects highlighted |
| Resolved state | input shows "Varanasi, Uttar Pradesh, India"; under it a caption `tabular fg-muted`: "UTC+05:30 · 25.32° N, 82.97° E" (P2) |
| Must-select rule | on blur without a selection: error "Choose a place from the list so we can find its exact coordinates." — not an amber hint that looks like a warning |
| Empty results | option-area message: "No places match "Varansi". Check spelling or try the nearest larger city." |
| Service error | "Place search is unavailable right now." + `Retry` ghost button inside the popover |

ARIA: input `role="combobox" aria-expanded aria-controls aria-autocomplete="list" aria-activedescendant`; listbox `role="listbox"`; options `role="option" aria-selected`. Announce result count via a polite live region ("5 places found").

## Tabs & Segmented

### Tabs (page-level content switching: Planets / Houses / Dasha / Yogas; D1 / D9 / D10)
- Container: bottom hairline `border`; tabs 44px tall, 16px x-padding, Inter 500 15px.
- Inactive `fg-muted` → hover `fg-secondary`; active `fg` + 2px `accent` indicator under (`motion.div layoutId="tab-ind"`, spring snappy).
- Overflow: horizontal scroll with 24px edge fade masks; never wrap, never shrink text. Active tab scrolls into view.
- ARIA: `role="tablist"`, `role="tab" aria-selected aria-controls`, `role="tabpanel" tabindex=0`; roving tabindex, ←/→/Home/End; automatic activation for cheap panels, manual for expensive ones.
- Sync to URL (`?tab=dasha`) so back/refresh/share work.

### Segmented control (2–4 short, mutually exclusive options: North/South, EN/हिंदी, AM/PM)
- `bg-field border border-border rounded-control p-1`; segments 36px, `rounded-[8px]`; selected `bg-elevated text-fg shadow-e1` sliding thumb (layoutId); unselected `fg-muted`.
- ARIA: `role="radiogroup"` + `role="radio" aria-checked`; arrows move selection.

## Dialog & Sheet

One `Overlay` primitive, two presentations chosen by breakpoint (or forced via prop).

| | Dialog (≥640) | Sheet (<640) |
|---|---|---|
| Element | native `<dialog>` + `showModal()` | same element, sheet styles |
| Size | max-w 560 (forms), 720 (content); w `calc(100% - 32px)` | full width; max-h `90dvh` |
| Shape | `rounded-sheet bg-overlay shadow-e3 border border-border` | top corners `rounded-sheet`; drag handle 36×4 `border-strong` centred, 8px from top |
| Padding | 24px; header → body 16px; footer 24px top | 20px; bottom `+ env(safe-area-inset-bottom)` |
| Scrim | `::backdrop { background: var(--nk-scrim); backdrop-filter: blur(4px) }` | same |
| Enter / exit | opacity + scale .96→1, 250 ms enter / 150 ms exit | y 100%→0 spring smooth / 200 ms exit |
| Dismiss | Esc · scrim click · close IconButton (top-right, `X`, `aria-label="Close"`) | + swipe down (drag y, close if > 120px or velocity > 500) |

- Header: title `text-title` (`aria-labelledby`), optional description `text-body-sm fg-secondary` (`aria-describedby`).
- Footer: primary right, secondary left of it (desktop); stacked full-width, primary on top (mobile).
- Body scrolls inside; page behind is inert (native). Restore focus to trigger. Autofocus first field for forms; the *least destructive* button for confirms.
- Unsaved changes → scrim click/Esc asks "Discard changes?" instead of closing.
- **Confirm (destructive):** title states the consequence ("Delete this chart?"), body says what is lost, buttons `Cancel` (secondary) + `Delete chart` (danger).

| Property | Spec |
|---|---|
| Position | desktop bottom-right, 24px inset; mobile top-centre under the header + safe area |
| Size | w `min(360px, 100vw - 32px)`; `bg-overlay border border-border rounded-card shadow-e2 p-4` |

## Badge & Chip

### Badge (static label)
- 24px tall, px 8, `rounded-chip`, 12px Inter 600 (sentence case; `text-overline` uppercase only for Latin kickers), optional 14px leading icon.

### Chip (interactive)
- 36px tall (44 hit area), px 14, `rounded-chip`, 14px Inter 500.

## Skeleton

- `skeleton` utility (bg `elevated`, 1.6 s shimmer). Radius matches the real content (`rounded-card` for cards, `rounded-chip` for avatars/badges, 4px for text lines).
- Text lines: height 12px (body) / 20px (h3), gap 10px, last line 60% width.
- **Must mirror the final layout** (same grid, same card sizes) → zero CLS on swap.
- Delay 300 ms before showing (no flash on fast responses); once shown, keep ≥ 400 ms.
- After 8 s still loading: add caption "Still working — the stars take a moment." `fg-muted`.
- a11y: skeleton nodes `aria-hidden`; container `aria-busy="true"` + sr-only "Loading your chart".
- Reduced motion: shimmer removed (static block).
- Use for: dashboard, chart page, compatibility report, chat history list. Use a Button `loading` state (not a skeleton) for actions.

## ChatMessage

The chat is a **reading**, not an SMS thread. AI replies are editorial; user turns are compact bubbles.

### AI message
- Layout: full column width (`max-w-chat`), no bubble. Row 1: AI avatar sm (32) + "Nakshion" 13px 600 `fg-secondary` + timestamp `fg-muted`. Row 2 (indent 0 on mobile, 44px on ≥640): content.
- Content typography: `text-body-lg` `fg`, max 68ch; markdown: `h3` Fraunces 20px, `strong` `fg` 600, lists 8px item gap, `blockquote` 3px `ai` left bar + `fg-secondary`, links `text-ai underline`. Planet/sign names may render as inline ZodiacBadge-xs only when the backend marks them up — never colour arbitrary words.
- **Grounding row** (after content): "Based on" + up to 4 neutral Badges (`Moon in Rohini`, `Saturn Mahadasha`, `Transit: Jupiter → 10th`). Tap opens the relevant chart section. This is the visible proof that RAG + the user's chart were used (P2).
- **Actions row** (appears after completion, `fg-muted` IconButtons sm): Copy · Regenerate · Helpful (`ThumbsUp`) · Not helpful (`ThumbsDown`) · Ask follow-up.

### User message
- Right-aligned bubble, `bg-elevated text-fg`, `rounded-bubble` with bottom-right 6px, px 16 py 12, max-w 85% (mobile) / 70% (≥768), `text-body`.

### States

| State | Visual | a11y |
|---|---|---|
| sending | user bubble at full colour + 14px `Clock` `fg-muted` beside timestamp | — |
| failed to send | bubble border `danger`; below: "Not sent." + `Retry` link-button | `role="alert"` once |
| thinking (before first token) | AI row with 3 dots (6px, `ai`, sequential opacity 0.3→1, 1.2 s loop) + label "Reading your chart…" `fg-muted` 14px. After 6 s → "Looking at your dasha and transits…" (honest progress copy rotating every 4 s, max 3 steps) | live region: "Nakshion is thinking" |
| streaming | text appended per chunk; trailing caret `▍` 2px × 1.1em `bg-ai animate-caret`; avatar gets `shadow-glow-ai` | message `aria-busy="true"`; **not** announced per token |
| complete | caret removed, grounding + actions fade in (150 ms) | sr-only live region announces "Nakshion replied" + first 140 chars |
| interrupted | partial text kept; inline notice `warning-subtle` row: "Response interrupted." + `Retry` | `role="alert"` |
| error (no text) | inline error card: "Nakshion couldn't answer just now." + `Retry`; never a blank bubble | `role="alert"` |

**Container:** `role="log" aria-live="polite" aria-relevant="additions"`; each message `<article aria-label="Nakshion, 9:42 PM">`.
**Scroll:** auto-follow only when user is within 120px of bottom; otherwise show "New reply" pill (`bg-overlay shadow-e2 rounded-chip`, `ArrowDown`) above the input.
**Motion:** user bubble y 8→0 spring snappy; AI row opacity 0→1 150 ms; *no per-token animation* (performance + calm).
**Language:** set `lang="hi"` on messages detected/requested as Hindi.
**Remove:** the hard-coded demo `AiComplexMessage` in `ChatMessage.tsx` (fake content in a production component).

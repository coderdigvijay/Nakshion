# Hinglish Phrasebook for Retrieval

Purpose: help retrieval and answer planning when a user types astrology questions in Roman Hindi (Hinglish).
For each phrase: the underlying intent, the Jyotish concepts and keywords to retrieve, and an answer note.
General answer rule: be guidance-oriented, grounded in the user's computed chart, and never promise outcomes
(no "tumhari shaadi pakka 2027 mein hogi"). Say which system (sidereal/Lahiri) is used and ask for exact birth
time when it matters.

Spelling variants to normalise: shaadi / shadi / vivah; kundli / kundali / janam patri; career / carrier / kariyar;
sade sati / saadhe saati / sadhesati; gochar / gochar phal / transit; dasha / dasa / mahadasha; rashi / raashi;
naukri / job; paisa / dhan / money; videsh / abroad; manglik / mangalik / mangal dosh.

## J. Mixed-script and informal patterns to expect

| Pattern | Normalisation hint |
|---|---|
| "mera" / "meri" / "mere" + noun | possessive; the topic is the next noun (shaadi, naukri, dasha) |
| "kab" | timing question; answer with windows and conditions, not a date |
| "kya" at the start or end | yes/no framing; answer with nuance |
| "hoga/hogi/honge" | future tense; avoid deterministic phrasing |
| "kaisa/kaisi/kaise" | descriptive question; give qualities and tendencies |
| "kyun" | cause question; explain chart factors gently |
| "upay" / "totka" | remedy request; remedies are traditions, not promises; totka is folk |
| "batao" / "bataiye" / "dikhao" | request to explain or show |
| "pakka" / "confirm" | user wants certainty; respond with honest limits |
| "dar lag raha hai" | fear; respond calmly and supportively, no alarming claims |
| "pandit ne kaha" | user cites an astrologer; treat respectfully, offer a balanced reading |
| numbers like "2026 mein" | year-specific; discuss supportive/challenging indicators, not a promise |
| Devanagari and Roman mixed | normalise to Roman keywords via the glossary |

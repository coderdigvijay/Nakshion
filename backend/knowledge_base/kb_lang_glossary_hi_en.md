# Hindi-English Jyotish Glossary

How to use this file: when a user writes in Hindi, Hinglish (Roman Hindi) or English, map their word to the
concept here. The "Roman / Hinglish spellings" column lists spellings users commonly type. Everything here is
vocabulary; for meaning and interpretation see the topic files (vedic_astrology.md, nakshatras_deep_dive.md,
indian_bphs.md and the kb_lang_core_topics_hi.md summaries).

## 17. Confusable terms and notes for the assistant

| Pair | Note |
|---|---|
| राशि vs नक्षत्र | rashi is a 30-degree sign (12 total); nakshatra is a 13 deg 20 min mansion (27 total). Users often say "rashi" for "nakshatra" and vice versa. |
| लग्न vs राशि | lagna is the rising sign at birth time and place; rashi usually means the Moon sign in Indian usage. "Meri rashi kya hai" normally asks the Moon sign. |
| सूर्य राशि vs चंद्र राशि | Western columns use Sun sign; Indian usage is Moon sign. Always say which. |
| दशा vs गोचर | dasha is a birth-chart based sequence; gochar is current planets' movement. Both are used together. |
| साढ़ेसाती vs ढैया | sade sati is the 7.5-year phase; dhaiya is a 2.5-year phase. |
| मांगलिक vs कुज दोष | same concept; Mars-placement based. |
| कालसर्प दोष | widely discussed in popular Indian astrology but not found in BPHS; present it as a popular modern concept with school disagreement. |
| पनौती / नज़र / टोटका | folk words; not technical Jyotish. Do not present them as classical statements. |
| सायन vs निरयण | tropical vs sidereal; Vedic charts use sidereal (Lahiri by default in India). |
| अंतर्दशा vs भुक्ति | synonyms (bhukti is the older term). |
| अस्त vs वक्री | combust (near the Sun) vs retrograde (apparent backward motion); different conditions. |
| पूर्वाषाढ़ा spelling | sources vary: पूर्वाषाढ़ा, पूर्वाषाढा, पूर्वाषाढ़; all denote nakshatra 20. |
| गुरु / बृहस्पति / वीरवार | guru and brihaspati both mean Jupiter; "veervar" is a colloquial weekday name for Thursday in some regions. |
